# SZUP_projekat_kalkulator
projekat za ispit

Ovaj projekat predstavlja jednostavan kalkulator napisan u programskom jeziku C.

Omogućava osnovne matematičke operacije kao što su sabiranje, oduzimanje, množenje i deljenje.

Projekat je namenjen za učenje i vežbanje rada u C jeziku i može se dalje nadograđivati dodatnim funkcionalnostima.
